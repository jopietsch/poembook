# Xteink X3 visual checks

Use CrossPoint's screenshot command to capture these pages after material EPUB
layout changes. Test both Medium and Large reader font sizes with embedded styles
enabled, 5–10 px margins, left alignment, and hyphenation disabled.

- a short metrical poem (`a1`, Love (III));
- a long-line poem (`a6`, The Windhover);
- an indented poem (`c6`, The Darkling Thrush);
- a long-poem movement (`as0`, The Hound of Heaven);
- a recall page at every cue level;
- Current rotation;
- the main contents and first-line index;
- both library cover thumbnails.

Check line wrapping, stanza gaps, lost glyphs, clipped headings, excessive blank
space, ghosting, and whether the full-text/recall chapter sequence remains clear.
Name captures `<edition>-<slug>-<font-size>.bmp`. Device screenshots are QA
evidence and should only be committed when they document a material rendering
decision.
